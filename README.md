# relatorio-final
## Resumo do que aprendi
## Sistemas de Informação
### Aprendi o que são Sistemas de Informação e como eles são formados por pessoas, processos, dados, tecnologia e regras. Também entendi a diferença entre um sistema de informação e um software. Aprendi qual é a função do Analista de Sistemas e como ele ajuda a entender os problemas e necessidades dos usuários antes do desenvolvimento do sistema.Aprendi a coletar informações para descobrir o que o sistema precisa ter, usando técnicas como entrevistas, questionários, observação e análise de documentos.
## Ciclo de Vida de Software
### Aprendi as etapas do desenvolvimento de um software, desde o levantamento e análise até o desenvolvimento, testes, implantação e manutenção. Também conheci os modelos Cascata, Iterativo/Incremental e Ágil.
## UML e Diagramas
### Aprendi o que é UML e como ela ajuda a representar um sistema através de diagramas. Estudamos principalmente Diagrama de Casos de Uso, Diagrama de Classes e Diagrama de Sequência. Aprendi que o include representa uma funcionalidade que é obrigatória, enquanto o extend representa uma funcionalidade opcional.
## Requisitos
### Aprendi sobre Requisitos Funcionais (RF), Requisitos Não Funcionais (RNF) e Regras de Negócio. Também aprendi sobre escopo, premissas, restrições e rastreabilidade.
